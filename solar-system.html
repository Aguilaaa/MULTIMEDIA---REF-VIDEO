3D Solar System

A Blender animation with procedural textures, orbital motion, and Python-driven scene setup—full overview below, plus per-body stats tied to the age calculator.

Final solar system animation

Full Blender render — camera tour from the Sun through each planet and out to the system view. Watch on YouTube: Final solar system (YouTube).

Project details

Built in Blender 3.3 with Python in the Scripting workspace. High-resolution textures from Solar System Scope. Script assets and notes are organized for Sun and each planet.

  • Render: ~13.5 hours; 1920×1080 @ 30 fps; 1890 frames (1:03).
  • Pipeline: Cycles, GPU-focused settings, camera tour from Sun through planets, zoom-out system view.
  • Python scripts: Use the View and Download buttons on each celestial body card (and the final animation) to read or save the Blender setup scripts.

Step-by-step workflow

This is the pipeline I followed for the solar system project: source the planet textures first, use AI to draft the Blender Python scripts, tweak them for my scene, then run and render each pass before assembling the final animation.

  1. 1

    Gather textures first

    Download high-resolution maps for the Sun and each planet from Solar System Scope. Organize them in one folder so every script can point to the same texture paths (including Saturn’s rings where needed).

    Tip: Name files clearly (e.g. 2k_earth.jpg, 2k_mars.jpg) before writing or editing any script.

  2. 2

    Plan each celestial body

    Decide what each script should build: mesh scale, orbital distance, rotation speed, camera framing, and render length. I kept a separate Python file per body (Sun, Mercury, Venus, etc.) plus one script for the full final render.

  3. 3

    Generate scripts with AI

    Used AI to draft the Blender Python setup for each planet—creating spheres, assigning textures, adding orbit empties, keyframing motion, and placing the camera. That gave me a working base instead of writing everything from scratch.

  4. 4

    Modify the scripts

    Edited the generated code to match my project: corrected texture file paths, adjusted distances and timing, tuned Cycles/GPU settings, and fixed camera distance so each body reads clearly in the final tour.

    Tip: Use the View buttons on each card below to read the finished scripts on this site.

  5. 5

    Run the scripts in Blender

    Open Blender 3.3, switch to the Scripting workspace, load a .py file, and click Run Script. Repeat for each celestial body to build the scene automatically instead of placing everything by hand.

  6. 6

    Preview and adjust in the viewport

    After each run, check materials, lighting, and camera framing in the 3D viewport. Small tweaks—exposure, scale, or orbit speed—were easier to fix in the script and re-run than to adjust manually every time.

  7. 7

    Render individual planet passes

    Exported close-up clips for each body (the embedded YouTube videos on this page). These passes became the per-planet showcase while the main timeline was still being finalized.

  8. 8

    Assemble the full animation

    Ran final_render.py to set up the complete camera tour—from the Sun through each planet and out to the wide system view—using the same textures and motion logic from the individual scripts.

  9. 9

    Render and export the final video

    Sent the full composition through the Render Queue with Cycles and GPU rendering (1920×1080 @ 30 fps, 1890 frames). The exported MP4 is the final 1:03 solar system animation shown at the top of this page.
